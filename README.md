## 📖 О программе

**Ployka AutoInstaller** — это удобная утилита с графическим интерфейсом (GUI), созданная для того, чтобы избавить вас от рутины. Программа автоматически скачивает и настраивает обход блокировок Discord и YouTube, а также предлагает установить необходимый софт (браузеры, Steam и другое) в пару кликов.

Больше не нужно искать инструкции, качать архивы вручную и разбираться с настройками. Всё уже сделано за вас.

## ✨ Основные возможности

- 🛡️ **Автоматический обход блокировок** — установка и запуск актуальных скриптов для Discord и YouTube (на базе `zapret`).
- 📦 **Выбор дополнительного ПО** — возможность отметить галочками нужные программы (На данный момент только одно стоит и это обход телеграмма от Flowseal TG WS Proxy) и установить их вместе с основной программой.
- 🖥️ **Информация о системе** — программа автоматически определяет ваше железо: процессор, видеокарту и объем оперативной памяти.
- 🔄 **Автообновление** — встроенная проверка новых версий через GitHub. Программа сама сообщит, если вышло обновление.
- 🎨 **Современный дизайн** — приятный темный интерфейс, плавные анимации кнопок и интуитивно понятное управление.

## 🚀 Как установить и использовать

1. Перейдите в раздел **[Releases](https://github.com/ewqa1161-gif/AutoInstaller_for_pc_Club/releases/latest)**.
2. Скачайте последний файл `ployka_vX.X.exe`.
3. Запустите скачанный файл (Windows может запросить права администратора — это нормально, так как программа устанавливает ПО).
4. Отметьте галочками дополнительное ПО, которое хотите установить.
5. Нажмите кнопку **«Установить»** и дождитесь завершения процесса.

> ⚠️ **Важно:** Для работы программы требуется стабильное интернет-соединение. Установщики дополнительного ПО могут запрашивать права администратора.

## 🛠️ Технические детали

Программа написана на языке **Python** с использованием библиотеки **Tkinter** для графического интерфейса.

**Используемые технологии:**
- `requests` — для скачивания файлов и запросов к GitHub API.
- `PowerShell (WMI/CIM)` — для сбора точной информации о комплектующих ПК.
- `PyInstaller` — для сборки проекта в единый `.exe` файл.
